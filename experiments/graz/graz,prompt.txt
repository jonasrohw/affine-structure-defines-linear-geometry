Before we had sentences that looked like this:

x, r_k, a_i, b_j

now the sentences will have this form:

x a_ijklmn f_i
x a_ijklmn g_l
x b_ijklmn f_i
x b_ijklmn g_l

These sentence associate subjects a_... and objects
b_... with attributes f_i and g_l.

The indices ijk refer to attributes f_i.

The indices lmn refer to attributes g_l.

To generate the training corpus, we first need to determine
the set of subjects and objects, see below.

Once we have them we sample a subject (or object), then
sample an attribute (f or g), then sample one of the three
indices. This then results in one training
sentence. Examples:

x a_012012 f_0
x a_012012 g_0
x a_567234 f_6
x a_567234 g_2

So the first three indices are for f attributes, the last
two indices for g attributes.

We have 10 f attributes 0..9 and 10 g attributes 0..9. This
means there are (10 choose 3) * (10 choose 3) = 120^2 =
14400 different subjects and 14400 different
objects. (Correct?)

We have two relations although these two relations are never
explicitly given in the data. (in the first part of the
project, they will be added later)

The first relation R0 holds between a subject and object whose
first three indices are the same, i.e., the f attributes are
the same.

The second relation R1 holds between a subject and object whose
last three indices are the same, i.e., the g attributes are
the same.

We will create a dataset of subjects and objects where each subject
has exactly one object for R1 and exactly one object for R2.

We can divide this dataset into a training set and a test
set. Both occur in the pretraining data, without difference.

But later we will add relation expressions (as in salzburg)
for the training data (not for the test data) to the
pretraining corpus. The hypothesis is that the relation
will then generalize to subjects/objects that have occurred
in relation expressions in the training data.

The expectation is that the embeddings learned for subjects
and objects would have the expected structure.  Subjects
(and objects) with the same ijk part should be similar.
Subjects (and objects) with the same lmn part should be
similar. We would test this in this initial part of the project.
