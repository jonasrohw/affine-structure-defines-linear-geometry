\section{Purpose}

This note documents the two synthetic setups used to test the following claims:

\begin{enumerate}
  \item \textbf{Low-frequency linear relation.} A relation supported by hidden attribute structure can become linear/affine even when each novel triple is seen only once.
  \item \textbf{High-frequency non-linear/non-affine relation.} A random relation with no attribute support can be memorized when repeated often, but it does not become an affine map that generalizes to unseen subjects.
\end{enumerate}

Here ``linear'' means that an affine map fitted from subject-side representations to object-side representations generalizes on held-out pairs. ``Non-linear'' is used operationally as \emph{non-affine memorization}: the model can assign high probability to trained random triples, but affine reconstruction from the relation-conditioned representation fails and does not generalize.

\section{Shared Synthetic Entity Structure}

Entities are synthetic subject tokens \(\subj{i}\) and object tokens \(\obj{j}\). Each subject and object is assigned a pair of hidden attributes:

\[
  \subj{i} \mapsto (f_i, g_i), \qquad
  \obj{i} \mapsto (f_i + \Delta_f \bmod n_f,\; g_i + \Delta_g \bmod n_g).
\]

The implementation samples globally disjoint subject/object attribute pairs where possible, so the entity vocabulary has strong attribute geometry. Attribute tokens are \(\fatt{k}\) and \(\gatt{k}\). The separator token is \(\sep\). Training is causal language modeling: for a sequence \(t_0,\ldots,t_m\), the input is \(t_0,\ldots,t_{m-1}\) and the target is \(t_1,\ldots,t_m\).

\subsection{Curriculum}

\paragraph{Phase 1: attribute scaffolding plus \(k=10\) pilot triples.}

All subject/object attribute sentences are included repeatedly. The first \(k=10\) relation triples are also repeated.

\begin{itemize}
  \item Attribute repeats: 8
  \item Pilot relation subjects: \(i=0,\ldots,9\)
  \item Pilot triple repeats: 256
  \item Total phase-1 sequences: 27,136
\end{itemize}

The concrete sentence templates are:

\begin{verbatim}
x a_i f_p g_q x          subject attribute sentence
x b_i f_r g_s x          object attribute sentence
x a_i r_0 b_i x          structured relation triple
\end{verbatim}

Concrete examples from the saved run:

\begin{verbatim}
x a_0  f_49 g_11 x       subject a_0 attributes
x b_0  f_56 g_22 x       object b_0 attributes
x a_0  r_0  b_0  x       phase-1 pilot triple

x a_9  f_16 g_55 x
x b_9  f_23 g_2  x
x a_9  r_0  b_9  x
\end{verbatim}

\paragraph{Phase 2: single-exposure novel triples.}

Phase 2 uses triples not present in phase 1. Each phase-2 triple is shown once:

\begin{itemize}
  \item Unique phase-2 triples: 1024
  \item Phase-2 repeats: 1
  \item Never-trained held-out triples after phase 2: 502
  \item Phase-2 learning rate: \(3 \times 10^{-4}\), constant during phase 2
\end{itemize}

Concrete examples:

\begin{verbatim}
x a_10 r_0 b_10 x        phase-2 single-exposure triple
x a_11 r_0 b_11 x        phase-2 single-exposure triple
x a_100 r_0 b_100 x      phase-2 single-exposure triple
\end{verbatim}

For example, the saved attributes include:

\begin{verbatim}
a_10:  f_51 g_28         b_10:  f_58 g_39
a_11:  f_63 g_29         b_11:  f_6  g_40
a_100: f_28 g_55         b_100: f_35 g_2
\end{verbatim}

\subsection{Metrics}

Two kinds of metrics are reported.

\paragraph{Behavioral recall.}
Given prompt \(\sep,\subj{i},\rel{0}\), evaluate whether the top logit is the correct object token \(\obj{i}\).

\paragraph{Affine representational map.}
Fit an affine map on seen subject/object pairs:
\[
  \hat{o} = Ws + b.
\]
Evaluate on held-out subjects by cosine and nearest-neighbor recovery among object vectors. The run records both embedding-space and unembedding-space maps.

\midrule

Unembedding affine cosine & 0.0652 & 0.9543 \\
Embedding affine nearest-neighbor accuracy & -- & 1.0000 \\

\paragraph{Finding.}
The expected phase shift occurs at the representational level: the relation becomes a near-perfect affine map after the single-exposure phase. Direct next-token recall does \emph{not} emerge in this setup. Thus this run supports the claim:

\[
\text{single-exposure structured triples} \Rightarrow \text{affine relational geometry},
\]

but not:

\[
\text{single-exposure structured triples} \Rightarrow \text{reliable top-1 factual recall}.
\]

\section{Experiment 2: Structured vs Random Relations at Matched Frequency}

\subsection{Goal}

Test whether frequency alone explains affine structure by training two relations with identical exposure counts:

\begin{itemize}
  \item \(R_0\): structured/attribute-supported relation.
  \item \(R_1\): random relation with no relationship to attributes.
\end{itemize}

The desired pattern is:

\begin{itemize}
  \item \(R_0\) should be more affine and more generalizable.
  \item \(R_1\) should be memorized when frequent, but remain non-affine and fail on unseen subjects.
\end{itemize}

\subsection{Relation Definitions}

\paragraph{Structured relation \(R_0\).}
The structured target is identity in entity index:
\[
  R_0(\subj{i}) = \obj{i}.
\]
Since \(\obj{i}\)'s attributes are a fixed shift of \(\subj{i}\)'s attributes, this relation is supported by the hidden attribute geometry.

\paragraph{Random relation \(R_1\).}
\[
  R_1(a_i) = b_{\pi(i)}
\]
where \(\pi\) is a random permutation generated from the run seed. This relation is not supported by the hidden attribute geometry.

\paragraph{Finding.}
The sweep separates structure from frequency:

\begin{itemize}
  \item At low matched frequency, \(R_0\) is strongly affine while \(R_1\) is not. At one repeat, \(R_0\) affine NN accuracy is 0.953, while \(R_1\) is 0.016.
  \item As frequency rises, \(R_1\) becomes memorized. At 64 repeats, \(R_1\) train accuracy reaches 1.000.
  \item Even when memorized, \(R_1\) remains non-affine and does not generalize: at 64 repeats, \(R_1\) eval top-10 accuracy is 0.016 and affine cosine is 0.035.
  \item \(R_0\) generalizes better behaviorally than \(R_1\), but its prompt-space affine score declines with high repetition. This suggests repeated direct training can move even a structured relation toward a more memorized prompt representation.
\end{itemize}

\section{Overall Conclusions}

\begin{enumerate}
  \item \textbf{Low-frequency structured relations can become affine.}
  In Experiment 1, 1024 single-exposure structured triples induce a very strong affine subject-to-object map: embedding affine cosine 0.946 and affine nearest-neighbor accuracy 1.000.

  \item \textbf{Affine geometry and direct recall are separable.}
  In Experiment 1, the affine map is strong but direct top-1 object recall remains near zero. The model learned the geometry without reliably using it as the top logit.

  \item \textbf{Random relations can be memorized at high frequency without becoming affine.}
  In the matched-frequency sweep, random \(R_1\) reaches perfect train accuracy at 64 repeats but retains near-zero affine/generalization metrics.

  \item \textbf{Attribute support matters independently of frequency.}
  At the same exposure count, structured \(R_0\) is consistently more affine and more generalizable than random \(R_1\), especially at low repetition counts.

  \item \textbf{High repetition changes the mechanism.}
  The cleanest affine signal for \(R_0\) appears at low exposure. With many repeats, \(R_0\) remains better than \(R_1\) behaviorally, but its prompt-space affine metric declines.
\end{enumerate}

\section{Caveats}

\begin{itemize}
  \item The ``nonlinear'' claim is a geometric/mechanistic claim about non-affine memorization, not a proof that a specific nonlinear submodule alone stores the random relation.
  \item The strongest positive claim is about affine representational structure, not direct top-1 factual recall.
  \item The matched-frequency sweep shows that high repetition can reduce the measured prompt-space affine score even for the structured relation.
  \item Runs reported here were CPU validation runs in the shared workspace. For paper-grade claims, rerun the same configs on rho1/rho2 with multiple seeds and larger settings.
\end{itemize}
