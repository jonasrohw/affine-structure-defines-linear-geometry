When the user says "write to file" or "write this to a file", take the previous response and write it directly to an appropriate file. No re-analysis, no re-thinking, no reformatting debate. Just do it.

**Why:** The user frequently asks for responses to be saved. It's a mechanical action, not a reasoning task.

**How to apply:** Treat "write to file" as a near-instant action. Pick a sensible filename, write the content, confirm. Done.
